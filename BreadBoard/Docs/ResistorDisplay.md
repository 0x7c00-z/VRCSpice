# 抵抗モデルとカラーコード

`Prefabs/Parts/R.prefab` のルートは `BreadboardResistorPart : BreadboardPart`。部品番号と通常の抵抗値ラベルを廃止し、FBX由来の本体・金属リード・4本の帯を表示する。

## 表示

- 有効数字2桁と倍率で表せる値は、数字2本・倍率1本・固定の金色帯で表示する。固定帯は見た目のみで、シミュレーションに許容差を導入しない。
- 倍率は10^-2〜10^9。金は10^-1、銀は10^-2。表現範囲は概ね0.1Ω〜99GΩで、この中でも有効数字2桁に一致しない1234Ω等はテキストにする。
- 判定では浮動小数点演算の誤差だけを許容する。値を別のE24値に丸めない。
- 表せない場合は4本とも本体と同じマテリアルへ戻し、抵抗値のみをG7書式＋Ohmで表示する。部品IDは表示しない。極端な値は指数表記になる。
- 値変更でコードとテキストを双方向に切り替える。マテリアルの色を直接書き換えず、各Rendererのマテリアル配列を差し替えるので別の抵抗へ色が伝播しない。
- プレビューは本体と金属・帯の全スロットを既存の半透明マテリアルへ切り替える。範囲外の値のテキストも表示する。

色の割当の参照：[Vishay color code chart](https://www.vishay.com/docs/49478/_dale_resistor_color_code_chart_vmn_ms0002_1612.pdf)。

## メッシュとPrefabの更新

FBXの `Resistor` には `Body`、`color0`〜`color3`、`Metal` がある。実際のスロット順はBody/color0/color1/color3/color2/Metalのため、Builderはマテリアル名から帯を対応付ける。

現在のFBXはメッシュローカルのYが長軸、先端中心がY=.005/.045、先端面がX=-.025。`BreadboardResistorBuilder.Install` が3ピッチ（30mm）へ長軸方向を0.75倍し、ボード面の+X方向へ正規化した `model/Resistor3Pitch.asset` を生成する。本体も長軸方向に縮めている。高さは元モデルを維持し、リード先端がボード内へ入る。先端を表面へ持ち上げる25mmの補正は行わない。元FBX・Blenderファイルは変更しない。

メニュー `Tools > Breadboard > Install modeled resistor` で派生メッシュ、専用マテリアル、R.prefabを更新する。FBXの寸法や軸を変更した場合はBuilderの変換も確認する。PrefabのGUIDを維持するため、既存CatalogやシーンのR参照を変更する必要はない。

## 検証

`Tools > Breadboard > Verify resistor colors`：1099項目。全倍率と2桁の組合せ、境界値、不正値、3桁以上の値、テキストへの切替・復帰、半透明化。

既存データ検証674項目、Playモードの動的表示47項目も通過。さらにUdon VM上で1TΩのテキスト表示から4.7kΩのカラーコードへの変更と同じ表示インスタンスの維持を確認。生成した例示画像でも帯と範囲外ラベルを確認した。ClientSimには既存のSDK初期化例外があるため、実VRChatでの複数クライアント試験を代替するものではない。
